# Muhammad Ahmed — Portfolio

Static portfolio site (plain HTML, CSS and a little JavaScript). No build step.

## Publish on GitHub Pages
1. Put all files from this folder in the root of your repo (e.g. `portfolio`).
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`.
3. Your site will be at `https://<username>.github.io/<repo>/`.

All paths are relative, so it works under a repo sub-path.
